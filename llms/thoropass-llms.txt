# Thoropass

> Thoropass is an auditor-led, AI-powered compliance and audit automation platform. It combines software (continuous compliance monitoring, evidence collection, vulnerability scanning, penetration testing) with expert auditor services to help companies achieve and maintain SOC 2, ISO 27001, HIPAA, PCI DSS, HITRUST and related frameworks. Thoropass exposes a Partner API secured with OAuth 2.0 and a hosted, OAuth-protected Model Context Protocol (MCP) server for agent access. Backed by Bain Capital Ventures.

## API
- Partner API (OAuth 2.0 Authorization Code + PKCE): https://api.thoropass.com
- Authorization server metadata (RFC 8414): https://api.thoropass.com/.well-known/oauth-authorization-server
- Token endpoint: https://api.thoropass.com/oauth/token/
- Dynamic client registration (RFC 7591): https://api.thoropass.com/oauth/register
- Token revocation (RFC 7009): https://api.thoropass.com/oauth/revoke-token/

## MCP
- Hosted MCP server (OAuth-protected, scope mcp:invoke): https://api.thoropass.com/mcp
- Protected-resource metadata (RFC 9728): https://api.thoropass.com/.well-known/oauth-protected-resource
- MCP documentation: https://docs.thoropass.com/mcp
